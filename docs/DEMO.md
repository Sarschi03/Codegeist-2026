# Five-minute demo

1. Start Vite and open **Checkout redesign**. Point out the fictional Fieldwork checkout capture, annotation pins, and Cart → Payment → Confirmation flow.
2. Select the mobile payment annotation in the Inspector and choose **Find context**. Open the evidence for PAY-156 and Mobile Accessibility Guidelines.
3. Choose **Link** on PAY-156 to connect existing work. Confirm the issue key appears on the annotation.
4. Add a screenshot with **Upload image**, screenshot paste, or drag and drop. Select **Annotate**, drag a region, and choose **Read screenshot text** to extract visible copy. Add your review note and save it.
5. Select labeled flow nodes and choose **Explain** or **Draft tasks**. Review the explicit dependencies. Open a generated draft to edit the summary, criteria and evidence. Export drafts as Markdown.
6. Save, reopen, and export the Trace workspace. In Forge on a developer site, load a real Jira project and issue type and confirm creation. Show the issue key on the canvas.
7. On an eligible Atlassian installation, use **Linked pages** on a Confluence result. In Trace Companion or an enabled MCP client, pass the workspace ID or the JSON from **Export selection for Trace Companion**.

The local demo displays fictional issues and documents. Real Jira creation is available through the installed Forge build.
