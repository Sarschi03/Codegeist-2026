# Codegeist-2026 · Trace

**Draw it. Connect it. Ship it.**

Trace is a visual workspace for teams to annotate screenshots, sketch flows, find related Jira work and Confluence pages, and turn the evidence into reviewable Jira drafts. The editor brings an Excalidraw canvas, a drawing rail and a contextual inspector together in one workspace.

## Run on this computer

Prerequisites are Node.js 22 or newer, npm and a Chromium-based browser. Use a Node version supported by the current Forge CLI for Atlassian deployment.

```powershell
cd C:\Sara\Migracija\Hachathon\trace
npm ci

```

The project on this computer is configured for a local Convex development deployment under the `sara-karakas1/trace-codegeist-2026` account project. If Convex is stopped, start it in a second terminal with `npx convex dev`. Open the localhost URL printed by Vite.

On a fresh checkout, Trace starts in IndexedDB **Demo mode**. The first visit opens the fictional Checkout redesign board. Use **Workspaces** to manage boards or start a template. The **Convex demo** badge means workspace records and images are stored in Convex and context search still uses fictional Jira and Confluence data.

### Configure another Convex development deployment

1. Run `npx convex dev --configure existing --dev-deployment local` and select the dedicated Trace dev project. For a cloud development deployment, choose `cloud` only on a verified Free team.
2. Generate a random secret of at least 32 characters. Set `TRACE_RELAY_SECRET` on the selected Convex deployment using `npx convex env set TRACE_RELAY_SECRET` and enter it when prompted.
3. Add matching `TRACE_RELAY_SECRET` and `VITE_TRACE_CONVEX=true` to the ignored `.env.local`. Keep the deployment and URL settings generated by Convex. Start Vite on localhost. The secret goes from the Vite server to Convex and stays out of the browser bundle.
4. To use IndexedDB with the same checkout, set `VITE_TRACE_CONVEX=false` and restart Vite. Each mode has its own data.

The relay is designed for one developer on localhost. Deploy the Forge build for organizational use. [Convex development CLI](https://docs.convex.dev/cli/reference/dev)

## What works

- Create, rename, duplicate, delete, favorite, search, import and export workspaces. Start from six templates.
- Draw and connect shapes, add sticky notes, paste or upload images, crop screenshots, and pin numbered annotations to selections or regions.
- Read screenshot text locally with on-demand English OCR. Inspect labeled steps, visual origins and explicit arrow dependencies.
- Use Context Magnet to find relevant work, see supporting excerpts, and flag possible duplicates. Add and link references to the canvas.
- Generate, edit, save and export evidence-backed tasks and bug drafts. Create Jira issues from an installed Forge build after reviewing the draft and explicitly confirming.
- Use autosave, manual save, revision checks, local crash recovery, PNG/SVG/JSON/Excalidraw export and both themes. Open the command palette with Ctrl/Cmd+K.

## Forge and Atlassian

The [Atlassian setup guide](docs/ATLASSIAN_INTEGRATIONS.md) covers developer-site setup, manifest registration, scopes, deployment and installation. The Forge build uses Atlassian identity, Forge KVS and user-scoped Jira/Confluence APIs. Rovo Companion, read-only MCP tools and a manual Teamwork Graph lookup are declared and depend on site entitlement, access and installation.

The checked-in manifest uses an unregistered app ID placeholder. Live installation, Jira issue creation, Teamwork Graph, Rovo and MCP require an authenticated developer site and must be verified there. The standalone demo performs local search and drafting against fictional sources.

## Checks

```powershell
npm run lint
npm test
npx playwright install chromium
npm run test:e2e
npm run build
npm run build:forge
```

Set `TRACE_TEST_OCR=true` to exercise bundled OCR in Playwright. Set `TRACE_TEST_CONVEX=true` and run Convex tests with `--workers=1` against a disposable development or demo dataset. Playwright overrides the developer database setting for its default IndexedDB run. The build output is in `dist`. Build Forge last before deployment.

## Project structure

| Path                           | Purpose                                                    |
| ------------------------------ | ---------------------------------------------------------- |
| `src/pages`                    | Workspace dashboard and editor                             |
| `src/components`, `src/styles` | Reusable UI and regular CSS                                |
| `src/canvas`                   | Excalidraw, image processing and selection tools           |
| `src/shared`                   | Validated models, deterministic analysis and task drafting |
| `src/data`, `convex`           | Local data, integration adapters and Convex functions      |
| `src/forge`, `manifest.yml`    | Forge resolvers, storage and Atlassian integrations        |

Trace uses React, strict TypeScript, Vite, Excalidraw, Lucide, Dexie, Zod, MiniSearch, Tesseract.js, Convex and Forge. The browser assets contain the OCR worker and English training data.
